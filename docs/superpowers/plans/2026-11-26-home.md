# Home do painel local Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar uma home em `/` com produção em andamento, atividade recente, nichos cadastrados e um espaço reservado (sem fonte) para notícias futuras; mover a lista de produções para `/producoes`.

**Architecture:** Frontend React com CSS Modules e React Query, consumindo apenas endpoints já existentes (`/productions`, `/productions/{id}/events`, `/profiles`). O campo `niche`, hoje descartado no read model do perfil, passa a ser exposto na API e preenchido por um campo opcional no cadastro. Nenhum endpoint de notícias é criado.

**Tech Stack:** React 19, React Router 7, TanStack Query 5, CSS Modules, Vite, Vitest/Testing Library, MSW, FastAPI/Pydantic.

**Spec:** `docs/superpowers/specs/2026-11-26-home-design.md`

## Global Constraints

- Progresso sempre em unidades observadas (“2 de 6 etapas concluídas”), nunca percentual de tempo.
- O bloco “Notícias dos nichos” é apenas espaço reservado: sem requisição de rede, sem manchete de exemplo e sem ação que não exista.
- Nenhum dado inventado. Estados vazios trazem frase + ação em texto; carregamento e erro usam frases curtas e `InlineError`.
- Estilo Espaço: hairlines, arestas duras, três tamanhos de texto (48/15/13), dados em `Space Mono`, sem grade de cards.
- Rotas: `/` = Home; `/producoes` = lista de produções. Menu começa com “Início”.
- Comandos no Windows usam `npm.cmd` (o `npm.ps1` está bloqueado pela política de execução).

## Review Focus

- Rota antiga: se `/` continuar mostrando a lista, a home não existe de fato → teste em Task 4 (heading “Início” em `/`).
- Dado de notícia inventado ou chamada externa no bloco reservado → teste em Task 3 (texto exato do placeholder e nenhum link de notícia).
- Nicho some entre cadastro e leitura, deixando a seção vazia sem motivo → testes em Task 1 (`_profile_view` expõe `niche`) e Task 3 (home mostra o nicho).
- Home dispara uma requisição de eventos por produção → teste em Task 3 (uma única chamada a `/events`).
- Produção sem estágios observados / lista vazia gerando número inventado → teste em Task 3 (estado vazio e ausência de percentual).
